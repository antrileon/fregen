# Brand assets

Put your permanent app images here. Use these exact names and restart or refresh the app:

- `logo.png`: header logo, ideally transparent PNG, square, at least 512 x 512.
- `hero.png`: main image on the home page, ideally vertical 5:7.
- `body-front.png`: default front body map image.
- `body-back.png`: default back body map image.

Photos uploaded inside the app are saved locally in the browser for previews. These files are for permanent brand/app artwork.
